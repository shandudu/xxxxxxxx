# 固定资产盘点、条码序列号与财税双账 PRD v1.0

## 目标

在采购资产和月度折旧基础上，建立“扫码盘点 → 账实差异处理 → 会计折旧/税务折旧分账”的固定资产控制闭环。

## 业务规则

1. 资产标识：固定资产支持条码和序列号，盘点任务保存当时的标识快照。
2. 盘点任务：按财务期间建立盘点任务，逐项记录是否找到、实际成本中心和差异类型（缺失、位置不符、损坏）。过账后任务不可重复过账。
3. 差异调整：缺失/损坏资产转为 RETIRED 并写入 COUNT_ADJUSTMENT 台账；位置不符自动变更成本中心并留痕。
4. 会计折旧：沿用原值、残值率和使用年限，按直线法计提并生成 `6602 → 1602` 凭证。
5. 税务折旧：独立保存税务累计折旧和税务净值，默认按原值/税务使用年限直线计提，不影响会计账面；输出本期财税折旧差额。

## 接口

- `POST /api/v1/erp/finance/fixed-assets/counts`
- `POST /api/v1/erp/finance/fixed-assets/counts/{id}/post`
- `POST /api/v1/erp/finance/fixed-assets/depreciation/dual-run?period_id={id}`

## 验收标准

- 盘点缺失资产过账后状态变更并产生差异台账，位置差异更新成本中心。
- 双账折旧分别记录会计/税务累计折旧、净值和本期差额。
- 同一资产同一期间重复执行不重复计提、不重复生成会计折旧凭证。
- 关账期间禁止盘点过账和折旧计提。
