# 中英双语业务字典与 Tips 配置 PRD V1.0

## 1. 目标

在现有业务字典中维护稳定 Key、中文值和英文值。状态标签、下拉选项及前端 Tips 可按当前界面语言自动选择文案，业务代码不依赖任何一种语言文本。

## 2. 数据规则

- `type_code + value` 是业务唯一键；修改中英文值不得改变业务 Key。
- `label_zh_cn` 为必填中文值，`label_en_us` 为可选英文值。
- 英文未配置时回退中文；中文不可用时旧数据继续使用兼容 `label`。
- 中文和英文使用长文本字段，允许配置确认提示、帮助信息以及带变量的消息。
- 兼容字段 `label` 暂时保留，由服务端同步为中文值，旧客户端无需同时升级。

## 3. 前端规则

- 当前语言为 `zh-CN` 时选择中文值。
- 当前语言为 `en-US` 时优先选择英文值，缺失则回退中文值。
- 切换语言时重建已缓存的字典选项，不需要刷新页面或重新请求。
- `getDictText(typeCode, key, fallback, params)` 用于 Tips；支持 `{variable}` 参数替换。
- 未加载或未配置字典时显示代码提供的 fallback，避免提示为空。

## 4. 管理端

- 字典数据表格展示字典 Key、中文值和英文值。
- 编辑表单支持长中文文案和长英文文案。
- 同一字典类型下 Key 不允许重复，中文值和英文值允许修改。

## 5. 验收标准

- 旧字典升级后中文值自动继承原标签，原有页面显示不变。
- 内置字典具有中英文默认值。
- 语言切换后已加载的字典选项即时更新。
- 英文缺失时正确回退中文。
- 带参数的 Tips 可正确替换参数。
- MySQL 迁移升级、降级、再次升级无损保留旧中文标签。
- 后端测试、MySQL 结构检查、前端类型检查和生产构建通过。
