# MES + ERP 核心业务模块 PRD

## 1. 目标

在现有 FBA 插件体系中形成从主数据到采购、库存、生产、质量和销售的闭环。现有物料、仓库、供应商、客户、设备、BOM、工序/工作中心/工艺路线和追溯插件继续作为唯一主数据来源，新模块不重复建主数据表。

## 2. 业务链路

1. 采购订单确认后允许分批收货。
2. 供应商收货自动创建或关联批次，并写入库存结存和不可变流水。
3. 工单创建时冻结产品、BOM 和工艺路线版本快照，展开物料需求和工序快照。
4. 已生效的工序物料计划在工单创建时转成投料分配快照，支持一个 BOM 组件分配到一个或多个工序。
5. 生产领料扣减库存；工序执行记录实际耗料和工序产出；生产退料回补原批次和原库位；报工将成品入库。
6. 来料、过程、终检和复检统一进入质量检验；检验项目、抽样方案、模板和标准用于逐项判定，不合格结果进入 NCR/MRB。
7. MRB 支持让步接收、返工、退供、报废和复检。退供与报废写库存流水，退供同时生成供应商退货单。
8. 销售订单确认后允许分批发货；批次物料只有质量状态为 PASS 才能发货。

## 3. 模块边界

| 插件 | 核心职责 | API 前缀 |
| --- | --- | --- |
| `inventory` | 实时结存、预留字段、不可变流水、库存调整、库存调拨 | `/api/v1/mes/inventory` |
| `purchasing` | 采购订单、供应商收货、供应商退货查询 | `/api/v1/erp/purchasing` |
| `operation_material` | BOM 组件到工艺工序的独立投料计划、校验和版本状态 | `/api/v1/mes/operation-material-plans` |
| `production` | 工单快照、投料分配快照、工序执行、实际耗料、领退料、报工、差异和看板 | `/api/v1/mes/production` |
| `quality` | 检验基础配置、逐项结果、四类检验、NCR、MRB、处置执行、供应商质量评分 | `/api/v1/mes/quality` |
| `sales` | 销售订单、质量门禁、库存发货 | `/api/v1/erp/sales` |

## 4. 关键规则

- 所有库存变化必须调用 `InventoryService.post_transaction`，不得直接修改结存。
- 每笔库存流水使用唯一幂等键；调拨生成 `TRANSFER_OUT` 与 `TRANSFER_IN` 两条流水。
- 库存不得过账为负数，也不得低于预留数量。
- BOM 明细不绑定工序。工序投料归属保存在独立工序物料计划中，并在工单创建时冻结为投料分配快照，避免污染产品设计 BOM。
- 工单创建后继续使用其快照，不受后续 BOM/工艺版本修改影响。
- 工序必须按顺序执行；实际耗料不得超过工单净领料量，也不能跨越投料计划限定的工序。
- 检验模板只有在包含检验标准且引用的抽样方案有效时才能生效；检验结果保留标准上下限和期望值快照。
- 采购收货数量不得超过订单行剩余数量；销售发货数量不得超过订单行剩余数量。
- 批次受控物料在收货、领料、报工和发货时必须提供批次。
- 不合格数量的 MRB 分配总量不得超过 NCR 数量；只有全部处置完成后 NCR 才能关闭。
- `RETURN_TO_SUPPLIER` 必须来源于供应商收货检验，并生成 ERP 供应商退货单。

## 5. 状态机

- 采购订单：`DRAFT → CONFIRMED → PARTIALLY_RECEIVED → RECEIVED`，草稿或未收货确认单可取消。
- 生产工单：`DRAFT → RELEASED → IN_PROGRESS → COMPLETED`。
- 工序执行：`IN_PROGRESS → COMPLETED`；同一工序同一时间只允许一个执行会话。
- 工序物料计划：`DRAFT → ACTIVE → INACTIVE`。
- 检验模板：`DRAFT → ACTIVE → INACTIVE`。
- 销售订单：`DRAFT → CONFIRMED → PARTIALLY_SHIPPED → SHIPPED`，草稿或未发货确认单可取消。
- 检验：`PENDING → COMPLETED`。
- NCR：`OPEN → UNDER_REVIEW → DISPOSED → CLOSED`。
- MRB：`APPROVED → EXECUTED`。

## 6. 验收标准

- 七个业务插件可被后端自动发现，模型、API 与菜单均能注册。
- MySQL 和 PostgreSQL、自动递增和雪花主键均提供菜单初始化/销毁脚本。
- 数据库执行 `create_all(checkfirst=True)` 后所有 `mes_*`、`erp_*` 模型表存在。
- 超级管理员侧边栏能返回五个新增菜单。
- 后端插件测试、前端类型检查和前端生产构建全部通过。
- OpenAPI 包含库存、采购、生产、质量、销售核心路径。
