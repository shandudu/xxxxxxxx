# ERP + MES 一体化项目总 Goal V1.0

## 1. 项目目标

将 F 盘项目建设为可部署、可演示、可验收的制造业 ERP + MES 一体化系统。核心业务必须形成一条可重复执行的闭环：

> 主数据 → 销售订单 → ATP/CTP → MPS/MRP → 补货/采购/生产 → 质量放行 → 发货签收 → OTIF → 客诉/RMA → NCR/CAPA/8D → 追溯与经营分析

数据库基线统一使用 MySQL；C 盘项目不作为运行时依赖。

## 3. 总体验收链路

### 3.1 计划供应链链路

销售订单确认 → ATP/CTP 评估 → MPS 导入 → MRP 净需求 → 安全库存补货建议 → 采购/生产建议释放 → 采购确认/供应商承诺 → 生产/收货 → ATP/CTP 自动重算。

### 3.2 制造质量链路

生产工单 → 领料 → 工序报工 → 完工入库 → IQC/IPQC/FQC → NCR/MRB → 返工/报废 → CAPA/8D → 批次正向/反向追溯。

### 3.3 交付售后链路

销售订单 → 发货 → 客户签收 → OTIF → 客诉 → RMA → 退货检验 → NCR/CAPA → 客户处理结果。

## 4. 剩余建设阶段

### 阶段一：项目基线与验收矩阵

- 统一各插件路由、权限、迁移、测试、演示脚本清单。
- 建立一键 MySQL 初始化、迁移、回滚、演示和验收命令。
- 清理只存在模型但没有页面/接口/测试的功能。

### 阶段二：基础平台能力

- 统一异常码、操作审计、业务事件、通知和待办。
- 补齐权限菜单、按钮权限、数据权限和关键操作幂等。
- 固化 Docker/环境变量/备份恢复/日志与健康检查基线。

### 阶段三：计划供应链增强

- MRP 与补货建议去重、合并、锁定和释放追踪。
- 采购/生产执行回写计划达成率。
- 缺料、延期、产能风险进入统一预警中心。

### 阶段四：制造质量增强

- 生产工单与检验批次、质量判定、返工工单、CAPA 根因关联。
- 质量成本、返工报废成本、供应商质量和过程能力分析。

### 阶段五：经营与现场看板

- 交付 OTIF、采购 OTIF、库存周转、缺料、OEE、FPY、质量成本、CAPA 逾期等 KPI。
- 支持按工厂、车间、产线、供应商、客户、物料和时间筛选。

### 阶段六：最终交付验收

- MySQL 全量迁移升级/回滚。
- 端到端演示数据和验收脚本。
- 后端全量测试、前端类型检查/构建、接口路由和权限扫描。
- 形成部署手册、业务操作手册、数据字典和已知限制清单。

## 5. 完成标准

- 核心三条端到端链路可以在干净 MySQL 上重复运行。
- 所有核心业务都有模型、迁移、接口、权限、前端入口和至少一个回归验证。
- 关键状态变化可审计、可追溯、可重算，重复执行不产生重复业务单据。
- `pytest`、MySQL 校验、迁移回滚/升级、前端 typecheck/build 全部通过。
