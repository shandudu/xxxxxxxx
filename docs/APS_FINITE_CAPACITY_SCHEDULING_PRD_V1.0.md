# MES + ERP APS 有限产能排程模块 PRD V1.0

## 1. 模块目标

APS 第一期把 MRP 下达形成的生产工单，转换为可执行的工作中心工序计划。系统需要回答四个核心问题：

1. 哪个工单的哪道工序在什么时间生产；
2. 使用哪个工作中心及其第几条并行产能通道；
3. 工作中心在计划周期内是否超负荷；
4. 已发布工序由哪个人员、班组或工位执行。

## 2. 本期范围

### 2.1 班次

- 维护班次编码、名称、开始/结束时间、休息分钟；
- 支持跨自然日夜班；
- 支持启用和停用；
- 班次作为工作日历的可复用时间模板。

### 2.2 工作日历

- 维护每周工作日和默认班次；
- 支持节假日、临时加班、停产等日期例外；
- 日期例外可覆盖班次和产能系数；
- 工作日历按生效日期、失效日期和优先级分配给工作中心；
- 未分配日历的工作中心使用周一至周五 08:00-17:00 默认日历。

### 2.3 有限产能排程

- 排程对象为 `DRAFT` 或 `RELEASED` 状态生产工单；
- 工序顺序来自工单工序快照；
- 准备、加工、排队和搬运时间来自工单对应工艺路线；
- 工作中心 `parallel_capacity` 转换为独立产能通道；
- 前向排程选择最早完工通道；
- 后向排程选择最晚可开工通道；
- 工序跨班次或非工作日时自动续排；
- 排程结果以版本保存，运行排程不会直接修改生产工单；
- 发布排程后，才回写工单计划开始和结束时间。

### 2.4 负荷分析

- 按工作中心统计排程时间窗内可用分钟；
- 可用分钟考虑班次、日期例外、工作中心并行通道和产能系数；
- 计划负荷仅统计准备时间和加工时间；
- 输出利用率、超负荷分钟和工序数量。

### 2.5 甘特图

- 甘特图按“工作中心 + 并行通道”展示；
- 工序条显示工单、工序、计划开始和结束时间；
- 已发布工序和超期工序使用不同颜色；
- 甘特图与工序排程明细共享同一份数据。

### 2.6 工序派工

- 只有已发布的工序排程可以派工；
- 可指派到人员、班组或工位，三者至少填写一项；
- 同一工序可拆分多张派工单；
- 未取消派工数量合计不能超过工序计划数量；
- 支持派工接收和取消；
- 派工人员使用 `sys_user` 物理外键。

## 3. 数据模型

| 表 | 用途 |
| --- | --- |
| `mes_aps_shift` | 生产班次 |
| `mes_aps_calendar` | 工作日历主表 |
| `mes_aps_calendar_day` | 日期例外 |
| `mes_aps_work_center_calendar` | 工作中心日历分配 |
| `mes_aps_schedule` | 排程版本 |
| `mes_aps_operation_schedule` | 工序排程快照与产能通道 |
| `mes_aps_dispatch` | 车间派工单 |

所有业务关联都使用明确物理外键。数据库升级只执行 Alembic 增量迁移，不运行 `fba init`。

## 4. 排程算法

### 4.1 工序负荷

```text
加工分钟 = 工艺路线加工时间 × 工单计划数量 ÷ 工艺路线基准数量
资源负荷 = 准备分钟 + 加工分钟
工序总历时 = 资源负荷 + 排队分钟 + 搬运分钟
```

小时/基准量和秒/基准量在运算时统一换算为分钟。

### 4.2 前向排程

1. 从计划时间窗开始或工单原计划开始时间开始；
2. 按工序顺序处理；
3. 在工作中心各并行通道中计算最早可用时间；
4. 跳过非工作时间并消耗班次可用分钟；
5. 选择最早完工通道；
6. 将工序结束时间加搬运时间，作为下一工序约束。

### 4.3 后向排程

1. 从工单计划结束时间或计划时间窗结束时间开始；
2. 按工序逆序处理；
3. 在各并行通道中计算最晚可用时间；
4. 逆向跳过非工作时间；
5. 选择最晚可开工通道；
6. 将工序开始时间减排队时间，作为上一工序约束。

## 5. 权限

| 权限码 | 说明 |
| --- | --- |
| `mes:scheduling:view` | 查看 APS 工作台 |
| `mes:scheduling:config` | 配置班次和工作日历 |
| `mes:scheduling:run` | 运行 APS 排程 |
| `mes:scheduling:publish` | 发布排程并回写工单计划时间 |
| `mes:scheduling:dispatch` | 创建、接收和取消派工 |

## 6. 一致性规则

- 已开始、已完成或已取消工单不能进入新排程；
- 工作中心必须启用生产和排程；
- 工单每道工序必须存在工作中心；
- 工单工序必须能找到对应工艺路线工序时间；
- 排程运行与排程发布分离；
- 发布时再次锁定并检查工单状态，防止排程后状态已变化；
- 派工创建、数量校验和排程工序状态更新在一个事务中完成。

## 7. 本期明确限制

- 不做多资源联合约束，例如人员技能、模具、刀具和物料齐套同时约束；
- 不做换型矩阵、相邻工单合批和清洗规则；
- 休息分钟在第一期按班次尾部扣减，不拆成多个班中休息区间；
- 工作日历保存时区名称，但第一期统一使用系统业务时区进行排程；
- 一个日历日期例外只能选择一个班次，多班制可通过工作中心并行能力表达，后续再升级为日期多班段；
- 新排程版本只处理本次选中的工单，不自动把其他已发布排程当作锁定占用；
- 甘特图第一期为只读，不支持拖拽后自动重排；
- 派工与生产执行已保持工单工序关联，但“接收派工后自动创建生产执行会话”留到车间终端模块。
