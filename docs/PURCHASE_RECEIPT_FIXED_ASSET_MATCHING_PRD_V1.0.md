# 采购入库 → 固定资产 → 发票匹配 → 入账折旧 PRD v1.0

## 目标

把采购收货、应付发票、三单匹配和固定资产账务串成一个幂等流程，避免设备采购入库后重复建卡或未匹配发票就入账。

## 流程

1. 选择已过账的供应商收货单，读取收货行、采购订单行和物料/供应商信息。
2. 按收货单自动生成 AP 发票（税率、日期、发票号可传入），同时建立付款计划。
3. 执行采购订单—收货—发票三单匹配；数量或价格存在差异时阻断资产入账。
4. 匹配通过后，以发票不含税金额生成固定资产卡片，原值关联 AP 发票和收货单，自动生成 `1601 → 2202` 凭证。
5. 后续按财务期间执行直线法折旧，生成 `6602 → 1602` 凭证；同资产同期间幂等。

## 接口

- `POST /api/v1/erp/finance/fixed-assets/from-receipts/{receipt_id}`
- `POST /api/v1/erp/finance/fixed-assets/depreciation/run?period_id={id}`

## 验收标准

- 收货单无明细、发票不存在或三单匹配异常时，资产和凭证事务全部回滚。
- 同一收货单重复调用返回原资产，不重复开票、建卡或入账。
- 资产卡片保存 `source_type/source_id/ap_invoice_id`，可追溯到收货单和 AP 发票。
- 匹配通过后资产原值等于发票不含税金额，折旧可在后续期间正常计提。
