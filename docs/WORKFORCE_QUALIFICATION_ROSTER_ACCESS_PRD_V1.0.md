# 人员资质、排班与生产准入闭环 PRD V1.0

## 1. 目标

建立“工种 → 技能等级 → 证书 → 岗位授权 → 班次排班 → 开工校验”的人员准入闭环。对于启用准入规则的工序或工作中心，系统必须在生产开工前自动校验当前操作人；任一强制条件不满足时禁止操作，并返回可定位的失败原因。

## 2. 范围

- 工种主数据：工种编码、名称、启停状态。
- 技能等级：等级编码、顺序和启停状态；等级顺序用于判断是否达到最低要求。
- 人员技能：人员对应工种的当前技能等级、评定日期、有效期和状态。
- 人员证书：证书类型、证书号、发证机构、有效期、证据链接和吊销状态。
- 岗位授权：按人员、工种、工作中心和可选工序授予有时效的岗位权限。
- 排班：复用 APS 班次，按人员、日期、班次、工作中心和工种排班。
- 准入规则：按工序和/或工作中心配置最低技能、必需证书、岗位授权及排班要求。
- 准入检查：生产执行开工、执行完工报工、成品报工和车间派工开工共用同一校验服务。
- 预警看板：30 天内到期证书、过期证书、有效授权和当天已确认排班。

## 3. 核心规则

1. 未配置启用规则的工序/工作中心保持兼容，不拦截现有业务。
2. 匹配到规则后，人员必须拥有对应工种且未过期的有效技能，等级顺序不得低于规则最低等级。
3. 规则要求证书时，证书类型必须一致，状态有效，且当前日期处于有效期内。
4. 规则要求岗位授权时，授权必须覆盖当前工作中心；工序级授权或工作中心通用授权均可，且当前日期处于有效期内。
5. 规则要求排班时，必须存在当前时刻生效的已确认排班；跨午夜班次同时检查当天和前一天排班。
6. 同一范围存在多个启用规则时，将其视为可替代的资质路径，满足任一路径即可操作。
7. 无法识别当前登录操作人时，在规则启用范围内直接禁止开工。

## 4. 状态与异常

- 资质状态：`ACTIVE`、`SUSPENDED`、`REVOKED`。
- 排班状态：`PLANNED`、`CONFIRMED`、`CANCELLED`；只有 `CONFIRMED` 可通过准入。
- 规则状态：`ACTIVE`、`DISABLED`。
- 拦截原因包括：技能缺失/过期、技能等级不足、证书缺失/过期、岗位授权缺失/过期、当前班次未排班、操作人缺失。

## 5. 验收标准

- 可维护工种、技能等级、人员技能、证书、岗位授权、排班和准入规则。
- 证书列表可区分有效、临期、过期、未生效和已撤销状态。
- 看板正确汇总人员资质与证书预警。
- 未配置规则时原生产开工成功；配置规则后，无资质人员开工返回冲突错误且不产生生产执行记录。
- 具备满足规则的技能、证书、授权及当前班次排班后，可正常开工和报工。
- APS 车间派工开工与直接生产执行开工的准入结果一致。
- MySQL 迁移可升级、回滚并再次升级，后端回归测试及前端类型检查通过。
