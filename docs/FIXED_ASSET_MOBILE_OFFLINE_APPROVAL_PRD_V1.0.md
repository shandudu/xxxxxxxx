# 固定资产移动盘点离线缓存、分区派工与差异审批 PRD v1.0

## 1. 目标

将固定资产扫码盘点扩展为可在车间弱网环境运行的移动闭环：任务按分区派工，移动端离线缓存扫码结果，联网自动同步；缺失、损坏和位置不符等差异必须经过审批并保留照片证据后才能过账。

## 2. 核心流程

1. 管理员按财务期间、分区和负责人创建盘点任务。
2. 盘点员在手机/PDA 扫码；无网络时记录到浏览器本地队列，恢复网络后自动按顺序同步。
3. 扫码结果幂等写入盘点行，实时计算账实差异；照片以证据字段随扫码结果保存。
4. 差异责任人补充证据并提交“通过/驳回”审批；缺失和损坏差异没有照片不得通过。
5. 所有差异审批通过后方可过账，过账继续执行资产状态/成本中心调整和生命周期台账记录。

## 3. 数据与接口

- 盘点任务新增 `zone_code`、`assigned_user_id`。
- 盘点行新增 `evidence_photo`、`evidence_note`、`approval_status`、`approved_by`、`approved_at`。
- `POST /fixed-assets/counts/{task_id}/scan`：在线扫码或离线队列同步。
- `POST /fixed-assets/counts/{task_id}/lines/{line_id}/approval`：差异审批。
- `POST /fixed-assets/counts/{task_id}/post`：审批校验通过后过账。

## 4. 业务规则

- 只有 `COUNTING` 任务允许扫码或审批；同一任务/资产保持一条盘点行。
- 位置不符自动标记 `LOCATION_MISMATCH`；未盘到标记 `MISSING`。
- `MISSING`、`DAMAGED` 通过审批时必须提供照片证据。
- 已审批通过的差异不可直接驳回；重新扫码会使该行回到待审批状态。
- 任务过账前所有非 `NONE` 差异必须为 `APPROVED`；过账后任务只读。
- 离线队列仅保存在当前设备浏览器，服务端以同步成功为准，失败记录保留待重试。

## 5. 验收标准

- 手机/PDA 无网络扫码后提示“已缓存”，恢复网络自动同步并刷新任务明细。
- 分区、负责人在任务详情可见；无效负责人不能建任务。
- 差异行可上传照片、审批通过/驳回；缺失/损坏无照片无法通过。
- 未审批差异无法过账，接口回滚不产生半笔调整。
