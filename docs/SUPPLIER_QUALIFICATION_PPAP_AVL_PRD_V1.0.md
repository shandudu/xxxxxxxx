# 供应商准入、样品承认、PPAP/APQP 与 AVL PRD V1.0

## 1. 目标

建立供应商从候选准入到淘汰的可审计闭环，并与现有 IQC、SQM 和采购订单联动：

`准入申请 → 资质提交 → 审厂 → 样品承认 → PPAP/APQP → 准入审批 → 物料级 AVL → 定期复审 → 延续/限制/暂停/淘汰`

## 2. 角色与权限

- 采购：发起准入申请、维护供应范围。
- SQE/质量：执行审厂、样品判定、PPAP审核。
- 准入审批人：批准或拒绝供应商准入。
- 供应商管理员：查看 AVL、组织定期复审和淘汰。
- 系统：在采购单创建和确认时执行供应商及物料级准入校验。

## 3. 核心规则

### 3.1 准入

- 新准入申请创建后，供应商质量状态变为 `PENDING`，采购暂时关闭。
- 提交申请必须包含资质文件清单。
- 同一供应商不能同时存在多个有效准入申请。
- 审批前必须至少有一次通过或有条件通过的审厂记录。

### 3.2 样品与 PPAP/APQP

- 样品按供应商、物料和轮次管理，允许多轮送样。
- 样品可关联质量检验；关联检验时，只有已完成且结果为 PASS 才能批准。
- PPAP 支持 Level 1-5、版本、文件清单、审批结论和有效期。
- PPAP 批准必须引用已批准的同物料样品。

### 3.3 AVL

- 准入审批必须至少有一个已批准 PPAP。
- 审批自动创建或激活供应商物料关系，并强制启用来料检验。
- 每个批准 PPAP 生成一条物料级 AVL，记录生效期、失效期和下次复审日期。
- AVL 状态为 `APPROVED` 或 `CONDITIONAL` 且 PPAP 未过期时允许采购。
- 历史供应商在未进入新准入流程前保持兼容；一旦进入流程，采购必须满足准入和 AVL。

### 3.4 定期复审与淘汰

- 到期 AVL 可批量生成复审任务，自动带入最近一次 SQM 评分快照。
- 复审结论：继续、有条件、暂停、移除。
- 暂停/移除同步更新供应商物料关系；当供应商没有任何可用 AVL 时，自动关闭采购并暂停合作。
- 继续/有条件通过会更新 AVL 有效期、复审期和供应商质量状态。

## 4. 数据与审计

- 准入申请、审厂、样品、PPAP、AVL、复审分别持久化，不覆盖历史审批证据。
- 所有关键决定记录操作人、决定时间、备注及证据清单。
- PPAP 版本在供应商和物料范围内唯一。

## 5. 验收标准

- 未提交资质的申请不能进入评审。
- 缺少合格审厂、已批准样品或 PPAP 时不能批准准入。
- 准入批准后自动生成物料级 AVL，供应商恢复采购资格。
- 非 AVL 物料、过期 AVL、过期 PPAP、暂停或淘汰供应商均不能创建/确认采购单。
- 定期复审可以延续、限制、暂停或移除 AVL，并正确联动供应商和供应商物料状态。
- MySQL 迁移、降级、闭环验证、后端测试和前端构建全部通过。
