# 模具全生命周期管理 PRD V1.0

## 1. 目标

建立从模具建档、上下模、生产冲次、寿命预警、保养维修、穴位质量到成本分析的闭环：

`模具台账 → 上模绑定工单 → 报工自动累计冲次 → 寿命/保养预警 → 下模 → 保养或维修 → 穴位验证 → 再上线/停用/报废`

## 2. 核心规则

- 每套模具绑定一台类型为 TOOL 的设备主数据，并绑定一个产品物料。
- 建档时按穴位数自动生成穴位台账。
- 模具只能装到可生产的生产设备；同一设备同时只能装一套模具。
- 可绑定工单，工单产品必须与模具产品一致。
- 生产报工按 `向上取整((合格数 + 报废数) / 有效穴位数)` 自动换算冲次。
- 同一生产报工只能生成一条模具使用记录。
- 达到保养周期自动生成预防保养单；未保养前禁止继续上模或报工。
- 达到设计寿命后自动暂停，禁止继续生产。
- 穴位质量失败自动封锁穴位并生成维修任务；全部穴位封锁时暂停整套模具。
- 保养/维修完工自动归集人工、材料和外协费用，并重置保养冲次。
- 报废时记录残值成本，保留完整履历。

## 3. 功能范围

- 模具台账、状态、设计寿命、预警比例和保养周期。
- 穴位台账、有效/封锁/维修/停用状态和缺陷累计。
- 上模、下模、设备与工单绑定、生产数量与冲次履历。
- 冲次保养、故障维修、质量维修及执行结果。
- 购置、保养、维修、改造、报废成本台账。
- 单套模具生命周期成本和单位冲次成本。
- 驾驶舱：在机、寿命预警、超寿命、保养到期、封锁穴位和未完工任务。

## 4. 验收标准

- 建档自动生成正确数量的穴位。
- 不可用设备、产品不匹配工单、超寿命或到期未保养模具不能上模。
- 工单报工自动累计模具及有效穴位冲次，重复请求不重复累计。
- 达到周期自动生成且只生成一个开放保养任务。
- 穴位不良能够封锁穴位并触发维修。
- 保养维修费用进入成本台账，单位冲次成本计算正确。
- MySQL 升降级、业务回滚验证、后端测试和前端构建通过。
