# 库存计价、应收应付、财务凭证与经营利润驾驶舱 PRD v1.0

## 1. 目标

在现有采购、库存、销售和生产成本链路上增加财务经营闭环：库存移动平均计价，客户应收、供应商应付，业务单据自动生成借贷平衡凭证，并在一个驾驶舱中查看库存价值、资金占用、收入、销货成本和毛利。

## 2. 业务口径

- 库存采用移动平均法：按库存交易时间顺序累计数量和价值；收货使用采购订单单价，生产入库使用已结转工单单位成本，出库按当时库存平均成本扣减。
- 库存计价期间按财务期间锁定，输出期初数量/金额、收货、发出、期末数量/金额、单位成本和价格覆盖率。
- 应收来源于客户发票；应付来源于供应商发票；收款/付款支持部分结算，剩余金额和逾期金额实时更新。
- 凭证首期支持：应收发票、应付发票、客户收款、供应商付款；发票按净额/税额拆分税费科目，每张凭证借贷平衡且按来源幂等。
- 经营利润：收入取 6001 主营业务收入，销货成本取 6401 销售成本，毛利 = 收入 − 销货成本。库存、应收、应付和现金收支作为经营占用指标。

## 3. 核心流程

1. 财务建立期间并维护币种和日期。
2. 期间内采购收货、生产入库、生产领料、销售出库持续沉淀库存交易。
3. 运行库存计价，检查价格覆盖率和负库存风险。
4. 创建客户/供应商发票，支持收款、付款和部分核销。
5. 由业务来源生成凭证，凭证按来源幂等并可追溯。
6. 经营驾驶舱展示库存价值、应收应付、现金流、收入、成本和毛利率。

## 4. 数据与权限

- `erp_finance_period`：财务期间。
- `erp_inventory_valuation`：物料期间移动平均计价结果。
- `erp_ar_invoice` / `erp_ar_receipt`：应收发票与收款。
- `erp_ap_invoice` / `erp_ap_payment`：应付发票与付款。
- `erp_gl_voucher` / `erp_gl_voucher_line`：总账凭证及借贷明细。
- 权限：`erp:finance:view`、`erp:finance:manage`、`erp:finance:valuate`、`erp:finance:ar`、`erp:finance:ap`、`erp:finance:voucher`。

## 5. 验收标准

- 相同期间重复计价不会产生重复有效记录。
- 库存收发数量、期末数量和库存交易账一致；缺少单价时覆盖率明确下降。
- 应收/应付部分结算正确更新剩余金额、状态和逾期金额。
- 同一业务来源重复生成凭证返回原凭证，不重复记账。
- 每张凭证借方合计等于贷方合计。
- 驾驶舱收入、销货成本、毛利与凭证明细合计一致。
- 关闭期间拒绝重新计价、开票和生成凭证。

## 6. 回滚

迁移 `a1c3e5f7b9d2` 可回滚八张财务表；验收脚本使用事务并默认回滚，不影响现有业务演示数据。
