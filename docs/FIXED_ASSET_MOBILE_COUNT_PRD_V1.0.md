# 固定资产扫码盘点前端、移动盘点与实时差异确认 PRD v1.0

## 1. 目标

在已有固定资产盘点任务、条码/序列号和差异过账能力上，提供适配手机/PDA 的连续扫码入口。盘点人员扫描条码或序列号后，系统即时回显资产账面信息，幂等更新盘点行，并实时识别位置不符、缺失等账实差异。

## 2. 核心流程

1. 财务人员创建盘点任务并获得任务 ID。
2. 移动端输入任务 ID，扫描资产条码或序列号；回车与按钮均可提交。
3. 后端按条码/序列号定位资产，同一任务重复扫描只更新原盘点行，不产生重复记录。
4. 录入实际成本中心后即时计算 `LOCATION_MISMATCH`；未找到资产返回明确错误，未扫描资产仍可按既有任务规则处理。
5. 页面实时刷新已盘数量、最近扫描资产和差异明细；确认无误后执行差异过账。

## 3. 接口

- `GET /api/v1/erp/finance/fixed-assets/lookup?code=`：按条码或序列号查询资产。
- `GET /api/v1/erp/finance/fixed-assets/counts/{task_id}`：加载盘点任务及明细。
- `POST /api/v1/erp/finance/fixed-assets/counts/{task_id}/scan`：幂等写入单次扫码结果。
- `POST /api/v1/erp/finance/fixed-assets/counts/{task_id}/post`：过账差异并锁定任务。

## 4. 业务规则

- 仅 `COUNTING` 状态任务允许扫码；已过账任务只读。
- `code` 匹配 `barcode` 或 `serial_number`，必须命中且资产未删除。
- 同一任务、同一资产只有一条盘点行；重复扫码更新该行。
- 未盘到资产标记 `MISSING`；实际成本中心与账面不一致标记 `LOCATION_MISMATCH`。
- 过账沿用既有规则：缺失/损坏资产转为退休，位置差异更新成本中心并写入生命周期调整台账。
- 期间关账与权限控制沿用财务资产权限，不新增数据库表，兼容 MySQL 8。

## 5. 前端验收标准

- 手机宽度下输入框、按钮纵向排列，扫码枪回车即可提交。
- 成功扫码后清空输入框并显示最近资产、任务已盘数量和差异类型。
- 可加载任务、查看明细、执行差异过账；接口错误以可读提示展示。
