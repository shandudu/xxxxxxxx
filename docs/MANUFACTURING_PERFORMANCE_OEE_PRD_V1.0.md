# MES 制造绩效分析（OEE）模块 PRD V1.0

## 1. 建设目标

在现有 APS 工作日历、工作中心、生产执行和设备停机数据之上，形成可追溯的制造绩效分析闭环，支持管理人员按日期和工作中心查看 OEE、设备可靠性、节拍、产能利用、停机 Pareto，并支持配置目标值和重建日快照。

本期不重复录入生产或停机数据，所有指标从现有业务单据实时计算；日快照用于后续经营报表、长期趋势和定时任务。

## 2. 用户与权限

| 权限 | 用途 |
| --- | --- |
| `mes:performance:view` | 查看总览、趋势、工作中心、设备可靠性、节拍、Pareto 和快照 |
| `mes:performance:target` | 配置工作中心 A/P/Q/OEE 目标及备用理想节拍 |
| `mes:performance:rebuild` | 重建指定日期范围的日快照 |

## 3. 数据来源

| 口径 | 来源 |
| --- | --- |
| 日历产能 | APS 班次、工作日历、工作中心日历分配、并行产能和产能系数 |
| 计划停机 | `mes_equipment_downtime.category = PLANNED` 且影响产能的区间 |
| 非计划停机 | `mes_equipment_downtime.category = UNPLANNED` 且影响产能的区间 |
| 完成数量与实绩工时 | 状态为 `COMPLETED` 的生产执行记录 |
| 理论工时 | 工艺路线工序标准运行时间 × 执行数量 ÷ 路线基准数量 |
| 良品与废品 | 生产执行的 `good_quantity`、`scrap_quantity` |
| 故障次数与维修时间 | 非计划设备停机事件和其有效重叠时长 |

## 4. 指标定义

所有时间指标以分钟保存，比例保留四位小数，数量与节拍保留六位小数。

### 4.1 OEE

- 日历产能时间 = 工作日历有效时长 × 产能系数 × 工作中心并行产能。
- 计划生产时间 = 日历产能时间 − 计划停机时间。
- 运行时间 = 计划生产时间 − 非计划停机时间。
- 时间开动率 A = 运行时间 ÷ 计划生产时间。
- 性能开动率 P = 理论运行时间 ÷ 运行时间。
- 质量率 Q = 良品数量 ÷（良品数量 + 废品数量）。
- OEE = A × P × Q。

A、P、Q 和 OEE 展示值上限为 100%。当分母为零时指标返回 0%，避免产生无穷值；同时由“来源执行数”和日历提示帮助用户定位数据缺口。

### 4.2 节拍与产能

- 实际节拍（秒/件）= 实绩运行分钟 × 60 ÷ 完成总数量。
- 理想节拍（秒/件）= 理论运行分钟 × 60 ÷ 完成总数量。
- 节拍效率 = 理想节拍 ÷ 实际节拍。
- 良品小时产出 = 良品数量 ÷（运行时间 ÷ 60）。
- 产能利用率 = 实绩运行时间 ÷ 运行时间。
- 闲置产能时间 = max（运行时间 − 实绩运行时间，0）。

若生产执行无法关联有效工艺标准，可使用工作中心绩效目标中的“备用理想节拍”；两者都不存在时，该执行不贡献理论工时，前端需展示数据完整性提示。

### 4.3 可靠性

- 故障次数 = 统计区间内开始的非计划停机事件数。
- MTBF = 可运行时间 ÷ 故障次数。
- MTTR = 非计划停机总时长 ÷ 故障次数。
- 设备可用率 =（观察时长 − 合并去重后的全部停机时长）÷ 观察时长。

同一设备的重叠停机区间合并后计时，避免维修单和人工停机重复登记导致时长翻倍。工作中心 OEE 使用 APS 日历产能口径；单设备可靠性第一期使用查询区间的自然时长作为观察时长。

## 5. 功能范围

### 5.1 制造绩效总览

- 日期范围、工作中心筛选。
- OEE、A、P、Q、目标达成工作中心数。
- MTBF、MTTR、实际/理想节拍、良品小时产出。
- 日/周/月趋势图。

### 5.2 工作中心与产能

- 对比各工作中心 OEE、A/P/Q、目标状态。
- 展示计划生产、运行、实绩、闲置和停机时间。
- 展示良品、废品、节拍、产出和来源执行数。

### 5.3 设备可靠性与停机 Pareto

- 按设备显示故障次数、计划/非计划停机、可用率、MTBF、MTTR、最近故障时间。
- 按非计划停机原因显示事件数、时长、占比和累计占比。

### 5.4 节拍分析

- 按工作中心、工序、产品聚合生产执行。
- 对比实际节拍、理想节拍和节拍效率。

### 5.5 目标与日快照

- 每个工作中心配置 A/P/Q/OEE 目标和备用理想节拍。
- 按 1～93 天、最多 200 个工作中心重建日快照。
- 同一日期和工作中心重复重建时更新原快照，不新增重复记录。

## 7. 数据表与约束

- `mes_performance_target`：工作中心绩效目标；工作中心为物理外键；有效记录唯一。
- `mes_performance_snapshot`：工作中心日快照；工作中心为物理外键；日期、工作中心和逻辑删除标记联合唯一。

数据库升级只允许执行 Alembic 增量迁移，不得在已有环境执行 `fba init`。

## 8. 一期边界与后续方向

- 一期质量率以生产执行良品/废品为准，后续可把 NCR、复检、返工后的最终判定纳入可配置质量口径。
- 一期只分析已完成执行，后续可增加班次实时 OEE、当前停机和在制工序的分钟级看板。
- 一期快照由授权用户手动重建，后续接入定时任务、消息告警和经营驾驶舱。
- 后续可增加设备与工作中心生效期绑定、原因代码树、六大损失、TEEP、工时数据完整率和多工厂对标。

## 9. 验收标准

1. 后端 10 个接口均纳入鉴权和权限控制。
2. 计划与非计划停机按类别影响对应的 OEE 时间口径，重叠区间不重复计时。
3. A/P/Q/OEE、节拍、MTBF、MTTR 的自动化公式测试通过。
4. 目标和快照表通过增量迁移创建，物理外键、唯一约束和索引存在。
5. “制造绩效”位于 MES 制造管理菜单下，目标配置和快照重建受按钮权限控制。
6. 前端通过类型检查和生产构建，实际运行接口不返回 4xx/5xx。
